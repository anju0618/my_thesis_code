# 実証分析（第4部）：2種類の分析

*[English](README.en.md)*

卒論第4部「実証分析」は，性質の異なる2つの分析から構成される。

## 分析1：既存アンケート調査データによる機械学習分析（`survey_regression/`）

ISSP（国際社会調査プログラム，日本，1996/2006/2016年）とWVS Time Series
（1981–2022年，Wave 1–7統合，日本サブセット$N=9{,}523$）の個票データを用い，
Random Forest回帰・SHAP・K-meansクラスタリングにより，政治的信頼・効力感を
規定する要因を検証する，マクロ・調査データレベルの分析（Python）。特に
WVS Wave 7（2019年）のデータではSNS利用頻度そのものを説明変数として
直接投入した分析を行い，統計的に有意な効果が見出せなかった。柔軟な機械学習
手法・個人単位のSNS変数を用いてもなお予測力が低いという結果を，卒論第4部
第1節（`subsec:methodology`）で述べる「マクロな態度指標だけでは政治的
分極化・疎外の実態を捉えきれない」という主張の実証的な裏付けとして用いる。
詳細は `survey_regression/README.md` を参照。

## 分析2：YouTubeコメントのLLM構造化コーディングによるミクロ分析（`llm_discourse/`）

分析1で見たようなアンケート調査ベースの指標では検出しにくい，感情的・物語的
分極化（affective / narrative polarization）を直接捉えるため，YouTube
コメントという生の言説データに対し，理論編で導入した概念（人民対エリート，
経済的怨恨，享楽の盗取等）をローカルLLMで構造化コーディングする，ミクロ・
言説レベルの分析。詳細は `llm_discourse/README.md` を参照。

## 両者の関係

分析1（マクロ・調査データ）では，OLSより柔軟なRandom Forest・SHAP・
クラスタリングといった機械学習手法を用いてもなお，人口統計学的変数だけでは
政治的信頼・効力感の分散のごく一部しか説明できないという結果が得られた。
これは分析1が捉えているのが**態度・信頼という静的な指標**だからにすぎず，
ポピュリズム的な動員は**具体的な言説・物語のレベル**（分析2が対象とする層）
でこそ生じている，という本稿の理論的主張（第\ref{sec:theory}〜\ref{sec:digital}部）
を実証的に裏付ける対比構造として，2つの分析を位置づける。

```
analysis/
  README.md                 # このファイル
  survey_regression/        # 分析1：ISSPによる機械学習分析（Python）
  llm_discourse/             # 分析2：YouTubeコメントのLLM構造化コーディング（Python）
```
